# Triage releases

This repository hosts Developer ID builds of Triage, SHA-256 checksums, and the signed Sparkle appcast.

- Appcast: https://kyndig.github.io/triager-releases/appcast.xml
- Downloads: https://github.com/kyndig/triager-releases/releases

The app repository publishes here from `.github/workflows/release.yml`. Signing keys and notarization credentials stay in the publishing environment and are never committed.
